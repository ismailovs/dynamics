# Glossary

| Term | Definition |
|------|------------|
| Dynamics | Microsoft Dynamics — a suite of enterprise resource planning (ERP) and customer relationship management (CRM) applications. |
| Terraform | An infrastructure-as-code (IaC) tool used to provision and manage cloud resources declaratively. |
| IaC | Infrastructure as Code — managing and provisioning infrastructure through machine-readable configuration files. |
| HCL | HashiCorp Configuration Language — the declarative language used by Terraform to define infrastructure. |
| State | A Terraform concept that tracks the current status of managed infrastructure resources (stored in `.tfstate` files). |
| Provider | A Terraform plugin that interacts with a specific cloud or service API (e.g., Azure, AWS, GCP). |
| Module | A reusable, self-contained package of Terraform configurations that encapsulates a set of resources. |
| Plan | A Terraform command (`terraform plan`) that previews changes before applying them to infrastructure. |
| Apply | A Terraform command (`terraform apply`) that executes planned changes to create, update, or destroy resources. |
| Resource | A single piece of infrastructure managed by Terraform (e.g., a virtual machine, database, or network). |
